# OCaml MDX

An OCaml library for parsing and rendering mdx-like markdown documents as react components.

## Credit / References

I stole a lot of code and ideas from the following projects:

- [ocaml-community/omd](https://github.com/ocaml-community/omd/tree/master): omdx is a fork of omd with some ast modifications at its core
- [dbuenzli/cmarkit](https://github.com/dbuenzli/cmarkit): lots of good information buried in here
- [mdx-js/mdx](https://github.com/mdx-js/mdx): i've never actually used it or read the codebase but i did read the readme
